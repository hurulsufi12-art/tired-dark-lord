[The Tired Dark Lord: A 100-Word Villain Monologue](https://make.fun/bounty/u-kevin-the-tired-dark-lord-a-100-word-villain-58b4f3cb).

`main.py` (Python 3, standard library only) writes a 102-word, 585-character
villain monologue to `/output/entry.txt` — no trailing newline, no network,
no model call, deterministic on every run.

Varkhul has ruled from the obsidian throne for three hundred years, and
still the goblins file his conquests under "miscellaneous."

## Run

```sh
python3 -P -s main.py
```

This writes `/output/entry.txt`. A custom output path can be given as the
first argument (ignored when it looks like a flag):

```sh
python3 -P -s main.py /tmp/entry.txt
```
